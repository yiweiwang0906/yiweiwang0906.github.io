文和友点菜单

  • 优先点：口味虾/蒜蓉虾 1 份，两人共享，要求少油少盐；补一份青菜或清爽凉菜。
  • 少量尝鲜：臭豆腐、糖油粑粑、猪油拌饭都偏油，建议每样只点一份分着吃。
  • 不建议叠加：油爆虾、烤牛油、炸串、甜饮同餐全上，会和你们“高蛋白、少油炸”的目标冲突。
  • 排队超过45分钟：先拍照逛楼，晚餐改去海信广场/坡子街周边湘菜，回程再买茶颜。

茶颜悦色健康排序

1 更轻负担素颜锡兰 / 纯茶类

优先无糖或三分糖，不加奶油顶和小料；适合当天已经吃了小龙虾/湘菜时搭配。

2 可选声声乌龙 / 栀子生椰

选三分糖、少冰，尽量去奶油或少奶油；茶香明显，甜腻感相对低。

3 经典但控量幽兰拿铁 / 桂花弄

经典款适合买一杯共享；奶油顶和坚果碎热量更高，建议三分糖、少奶油。

4 偶尔尝鲜蔓越阑珊 / 抹茶葡提 / 加小料款

水果糖浆、奶油、葡萄干/面包碎叠加后糖脂更高，放在步行量大的一天少量尝。

首选：湖南博物院文创

马王堆/辛追主题丝巾、冰箱贴、书签、香囊，小而精致，适合送人也适合自留。购买点：湖南博物院文创商店。

茶颜悦色周边

茶包、小莲罐、杯子、帆布袋、冰箱贴，包装好看且不占箱。购买点：五一广场/IFS 周边茶颜门店或茶颜文创集合店。

李自健美术馆纪念品

画册、明信片、帆布袋，适合偏安静文艺风的纪念。购买点：美术馆商店，看完展顺手买。

酱板鸭、臭豆腐礼盒、剁椒适合爱辣的人，但味道重、液体/酱料要看高铁携带和包装密封，尽量买小包装。

怎么分享给你太太看？

这个页面是单文件静态网页，文件名为 changsha_Travel.html。最省事的分享方式有三种：

  1. 直接发文件：把这个 HTML 文件通过微信/邮箱/网盘发给她，她用手机浏览器打开即可。高德 App 链接在手机上更好用。
  2. 放到 GitHub Pages：把仓库推到 GitHub，Settings -> Pages，选择 main 分支发布；生成的网址两个人都能打开。
  3. 用 Netlify / Vercel：把整个文件夹拖到 Netlify Drop，或导入 Vercel，几分钟就会得到公开链接。

如果只想家庭内部看，推荐“直接发文件”或“Dropbox/OneDrive 共享链接”。如果希望像正式网页一样随时访问，推荐 GitHub Pages。
